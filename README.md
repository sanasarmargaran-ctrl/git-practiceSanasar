# Система управления библиотекой на PHP

## Инструкция по запуску
1. Убедитесь, что установлен PHP версии 8.0 или выше.
2. Склонируйте репозиторий:
   git clone <URL_РЕПОЗИТОРИЯ>
3. Перейдите в каталог:
   cd git-php-practice
4. Запустите проект через встроенный веб-сервер:
   php -S localhost:8000
